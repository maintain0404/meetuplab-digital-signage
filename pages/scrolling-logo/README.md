# Scrolling Logo

배경에서 로고들이 여러 열로 각기 다른 속도로 수평 이동하고, 정중앙에 잊을 수 없는 대형 히어로 로고가 떠오르는 화면입니다.

## 특징

- 9개 행의 로고가 교대로 좌우 방향으로 무한 수평 스크롤
- 각 행마다 속도와 투명도가 다르게 설정되어 입체감 표현
- 중앙 히어로 로고: 부드러운 부유(float) 애니메이션 + 미러 반사 효과
- 어두운 모드: 다층 네온 글로우 (drop-shadow)
- 밝은 모드: 시네마틱 깊이감 그림자
- 비네트 효과로 시선이 중앙에 집중

## 쿼리 파라미터

| 파라미터 | 가능한 값 | 기본값 | 설명 |
|---------|---------|--------|------|
| `theme` | `light`, `dark` | 시스템 기본값 | 밝음/어두움 모드 |
