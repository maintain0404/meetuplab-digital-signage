# Logo Vinyl

회전하는 LP 레코드판의 중앙 라벨에 로고가 박혀있는 화면입니다. 레코드가 33⅓ RPM으로 천천히 돌고, 톤암이 좌우로 부드럽게 스윕하며, 바늘 주변에서 동심원 사운드 웨이브가 퍼져나갑니다. 하단에는 이퀄라이저 바가 리듬처럼 튀고, 배경에는 먼지 입자가 떠다닙니다.

라벨 안쪽 로고는 레코드의 회전과 반대로 역회전(counter-rotation)하여 **항상 정면으로 읽히도록** 설계되어 시청자의 기억에 강하게 각인됩니다.

## 쿼리 파라미터

| 파라미터 | 가능한 값 | 설명 |
|---------|---------|------|
| `theme` | `light`, `dark`, (빈 값) | 표시 모드 (비어있으면 시스템 기본값) |

**예시 URL:**
```
./index.html?theme=dark
```
