# Logo Tunnel

로고들이 원통형 터널 벽을 이루고 그 안을 끝없이 날아가는 웜홀 화면입니다.

## 특징

- **28개 링** × **8개 로고**가 헬리컬(나선형)로 배치된 3D 원통 터널
- 원근 투영(perspective projection)으로 가까운 링은 크게, 먼 링은 작게 렌더링
- 링 사이를 연결하는 케이지 라인으로 터널의 입체감 강조
- 중앙 히어로 로고가 forward 방향을 바라보며 자체 펄스 애니메이션
- 원근 스타필드(별 220개)가 날아가는 속도감 부여
- 속도가 사인파로 호흡하듯 완급 조절
- 중앙 안쪽에서 뿜어나오는 퍼플/앰버 글로우링

## 쿼리 파라미터

| 파라미터 | 가능한 값 | 설명 |
|---------|---------|------|
| `theme` | `light`, `dark`, (빈 값) | 표시 모드 (비어있으면 시스템 기본값) |

**예시 URL:**
```
./index.html?theme=dark
./index.html?theme=light
```
